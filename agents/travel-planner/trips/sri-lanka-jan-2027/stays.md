# Stays — sleep-only strategy

**Goal:** Freshen up + sleep. No resort amenities. Save money for driver, whales, food, casino cash.

## Rules

| Rule | Detail |
| --- | --- |
| Target | **USD 25–45 / night** for one room / 3 adults |
| Hard ceiling | **USD 50 / night** (only if nothing cheaper sleeps 3 cleanly) |
| Dropped | 3★ branding, pool hotels, Grand overnight, beachfront premium |
| Must have | Clean private bathroom, fan or AC, lockable door, early checkout OK |
| Must confirm | “3 adults one room” in writing before pay |
| Location | Near food / driver pickup — not scenic view premium |
| Skip paying for | Breakfast buffet (buy outside), late checkout, spa |

## Per-base search focus (indicative bands)

| Base | Nights | Search for | Aim / night |
| --- | --- | --- | --- |
| Colombo | 1–2 | Guesthouse / lodge near Fort, Slave Island, or casino-access tuk-tuk zone | $30–45 |
| Kandy | 1 | Simple lodge / guest house near lake or town (noise OK) | $25–40 |
| Nuwara Eliya | 2 | Basic lodge near New Bazaar / town — **not** Grand | $30–45 |
| Ella | 1 | Backpacker private room / simple inn walkable to Main St | $30–45 |
| Mirissa | 2 | Guesthouse **back from beach** (harbour-side OK for 6am whales) | $30–45 |
| Negombo (if needed) | 0–1 | Airport-area cheap lodge only | $25–40 |

Grand Hotel = **tea/visit only** (already locked).

## Where to search (mandatory order)

1. **Agoda** (first)  
2. **MakeMyTrip** (second)  
3. **Booking.com** — last resort only if Agoda/MMT lack a usable triple / extra-bed listing  

MASTER-PLAN stay links follow this order. Do not default to Booking.com.

## What to filter on Agoda / MMT

- Room type: **Triple** / Family / Double + extra bed  
- Guest rating: **7.5+** enough (don’t chase 9.0)  
- Free cancellation when possible (January peak)  
- Photos of bathroom + beds for 3  
- Message host: late return after casino (Colombo) and **pre-dawn exit** for whales (Mirissa)  
- Confirm total with taxes in **INR** before pay
