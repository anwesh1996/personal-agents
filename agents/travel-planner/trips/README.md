# Trips

One folder per trip: `trips/<trip-name>/`.

Suggested files (copy from `../templates/` and rename):

| File | Purpose |
| --- | --- |
| `trip-details.md` | Locked brief for this trip |
| `itinerary.md` | Day-by-day plan |
| `budget.md` | INR breakdown |
| `bookings.md` | Tracker only — user books |
| `checklist.md` | Prep checklist |
| `sources.md` | Citations |

Do not mix facts across trip folders.
