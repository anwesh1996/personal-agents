# Trips

One folder per trip: `trips/<trip-name>/`.

Suggested files (copy from `../templates/` and rename):

| File | Purpose |
| --- | --- |
| `trip-details.md` | Locked brief for this trip |
| `MASTER-PLAN.md` | **Canonical** locked plan (write after user locks decisions) |
| `itinerary.md` | Day-by-day working plan |
| `budget.md` | INR breakdown |
| `bookings.md` | Tracker only — user books |
| `checklist.md` | Prep checklist |
| `sources.md` | Citations (including YouTube + restaurant review sources) |

`MASTER-PLAN.md` must include YouTube links for named stops and recent good/caution reviews for named restaurants when available. See skill references `youtube-enrichment.md` and `restaurant-reviews.md`.

Do not mix facts across trip folders.
