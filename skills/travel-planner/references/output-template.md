# Output Template

Use this as the default structure when presenting a completed trip plan in chat before writing it to Wanderlog.

## Recommended order

1. Trip summary
2. Key assumptions and constraints
3. Day-by-day itinerary
4. Budget outline
5. Paid attraction / entrance fee notes
6. Transportation cost notes
7. Flight options (best / cheap / avoid) with party totals
8. Hotels with approx nightly and stay totals
9. Food and restaurant notes
10. YouTube links for named stops
11. Restaurant review takeaways (good + caution)
12. Free vs paid stop guidance
13. Packing notes
14. Cultural etiquette and practical cautions
15. Booking / prep timeline
16. Locked MASTER-PLAN path + trip.json (after user lock)
17. Optional Wanderlog execution plan

## Trip summary

Include:

- destination
- dates and trip length
- traveler count / type
- optimization priorities
- pace
- daily rhythm
- budget framing

## Key assumptions and constraints

Call out:

- any missing data you inferred
- fixed must-dos
- hotel / base assumption
- seasonal or holiday context
- weather or reservation pressure

## Day-by-day itinerary

For each day, aim for:

- day theme / area
- realistic start time
- main anchors in logical order
- meal placement that matches the route
- transit notes between major moves
- booking / caution notes
- fallback option if weather or energy changes the day

## Budget outline

Include a practical budget view:

- accommodation
- food
- transportation
- activities / tickets
- contingency buffer

## Paid attraction / entrance fee notes

List any ticketed stops you recommended with:

- likely fee
- whether it needs advance booking
- whether it is core or optional

## Transportation cost notes

Call out costs that materially affect the trip, such as:

- airport transfer
- local transit day-to-day estimate
- transit pass or stored-value card recommendation
- expensive long-distance or special transport moves

## Flight options

Include three positioned options (best/optimal, cheap, avoid/trap) with party and per-person estimates, `as of` timestamp, and planning-lock band. Follow [flight-hotel-pricing.md](flight-hotel-pricing.md).

## Hotels with approx pricing

For each overnight base: recommended option or band, approx / night, approx stay total, room rules, search link. Mark estimated vs verified.

## Food and restaurant notes

When food matters to the trip, call out:

- whether meals are highlights or just route-friendly coverage
- named restaurant suggestions vs neighborhood guidance
- likely cost level for important meal anchors
- whether reservations matter
- any must-eat dishes or local specialties

## YouTube links for named stops

For each named stop in the plan (and in MASTER-PLAN after lock):

- one practical YouTube guide when available (prefer last 6–12 months, any language)
- format: `Place — YouTube: <url> (title · ~Mon YYYY · lang)`
- or `YouTube: not found`
- follow [youtube-enrichment.md](youtube-enrichment.md)

## Restaurant review takeaways

For each named restaurant:

- 1–2 recent **good** takeaways and 1–2 **caution** takeaways (prefer last 6–12 months)
- note source type and approx date
- or `Reviews: not found`
- follow [restaurant-reviews.md](restaurant-reviews.md)

## Free vs paid stop guidance

Help the traveler trim cost by classifying major stops as:

- free
- paid but core
- optional paid upgrade

## Optional Wanderlog execution plan

When the user wants the trip written into Wanderlog, summarize:

- whether to create or update the trip
- hotel to add
- day-by-day places and practical notes
- any checklist items
- any actual expenses the user wants tracked
